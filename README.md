# 🧮 String Calculator

A sleek, React-based **String Calculator** app with a Neumorphic design. It parses and evaluates numeric strings with support for:

- Default delimiters (`+`, `,`)
- Custom delimiters (e.g., `//;\n1;2`)
- Arithmetic operations: `+`, `-`, `*`, `/`, `%`
- Multiline & escaped input handling
- Input via UI buttons or keyboard
- Full unit test coverage with Jest

---

## 📸 Preview

> Neumorphic calculator style with soft UI and round buttons.  
> Input and output area updates based on parsed string or arithmetic.

---

## 🚀 Features

- ✅ Real-time string parsing and math operations
- ✅ Custom delimiter support (`//[delimiter]\n[numbers]`)
- ✅ Error handling for invalid expressions
- ✅ Backspace (`DEL`) and reset (`clr`) controls
- ✅ Keyboard support (`Enter`, numbers, operators)
- ✅ Jest test cases for core logic
- ✅ React hooks (`useState`, `useEffect`, `useRef`)
